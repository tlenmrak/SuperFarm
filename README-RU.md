# SuperFarm

Репозиторий содержит минимальный пример потоковой передачи с **iPhone** через **Janus SFU**.  
Включает в себя:

- сервис сигналинга на **Spring Boot**
- небольшой браузерный клиент, который проксирует WebRTC-сообщения через слой сигналинга в **Janus**

---
## 🚦 Сервер Janus
Используйте предоставленный файл `docker-compose.yml`, чтобы запустить экземпляр Janus,
настроенный для этого демо.
Он открывает WebSocket-транспорт на порту `8188` и
слушает RTP по UDP-порту `5004`.

```bash
docker compose up janus
```

Janus будет считывать свою конфигурацию из файлов в директории janus/,
чтобы включить поддержку WebSocket и настроить потоковый mountpoint с ID 1.
## 🚦 Сервис сигналинга

Исходный код: `signal-service`

Сервис предоставляет **WebSocket-эндпоинт** по адресу `/ws`и перенаправляет все сообщения на сервер **Janus**, указанный в свойстве:

janus.url (по умолчанию — `ws://localhost:8188/`)

### ▶ Запуск

```bash
cd signal-service
mvn spring-boot:run
```
## 🚦 Демо фронт

Минимальный пример фронтенда доступен в каталоге frontend.
Он использует Janus JavaScript library для:

запроса плагина стриминга

отображения удалённого видео-потока

Раздайте статические файлы через любой веб-сервер, например:
```bash
npx http-server frontend
```

## 🚦 Сервис VideoBuss
Папка videobuss теперь содержит сервис на Spring Boot, который эмулирует источник видео. Когда сервис сигналинга запрашивает запуск,
он считывает MJPEG-файл и использует ffmpeg для транскодирования кадров в H.264, после чего отправляет их в Janus по RTP.

Поместите MJPEG-файл в videobuss/src/main/resources/video.mjpeg или измените свойство video.file. Затем запустите сервис:

```bash
cd videobuss
mvn spring-boot:run
```

По умолчанию сервис слушает порт 8081 и предоставляет эндпойнт /start, вызываемый сервисом сигналинга с информацией о RTP-соединении.
После активации на фронтенд-демо будет выводиться транслируемое видео.
